# Contributing

Describe the problem and include browser/OS, viewport and reproduction steps. For animation defects, compare the source clip with the selected frames at actual interaction speed. Keep generated media changes separate from controller changes when possible.

Run `npm test`, `npm run audit` and `npm run build`. For processing changes install `pipeline/requirements.txt` and run the Python tests. Include only media you can distribute and update its provenance. Never include API keys, source receipts or private inputs. Paid generation is not needed for the test suite.
