# Brief for your coding agent

Give the agent this repository’s URL or folder, then paste:

```text
Build my interactive clothing website using this repository.
Read AGENTS.md and START-HERE.md, then execute docs/agent-workflow.md.

Start by setting up and opening the included example. Take care of runtime discovery, local tools, installation and testing within your permissions. Do not make me design the architecture or carry out terminal steps you can perform.

Then ask for one product’s photos or original artwork and the visual direction. Inspect your available image/video tools and help me connect any missing account privately. Prepare and show the front/profile pair for my review. Before uploading or generating paid media, propose the provider, settings, cost, attempt limit and total cap.

Generate or import the turn, process its background, preserve the fixed pivot, update the catalog and test the actual hover/touch experience. Show the local website and help me refine it. Keep the result local until I approve publication. Track receipts and spending so interruptions never cause duplicate requests.
```

The agent follows the complete [execution guide](../docs/agent-workflow.md) and uses these prompts as needed:

- [Front view from a product photograph](image-front.md)
- [Front view with your own print](printed-shirt-front.md)
- [Matched strict side profile](image-profile.md)
