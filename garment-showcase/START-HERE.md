# Start with your AI agent

Paste this repository’s URL into a development chat in Codex or Claude Code. If you downloaded a ZIP, give the agent the extracted folder instead.

```text
Set up this project and open the working example for me.
Read AGENTS.md and follow docs/agent-workflow.md.
Then guide me through adapting it to my own product.
Handle installation and technical steps yourself; ask me only for
missing inputs, account access, visual decisions and spending approval.
Keep everything local until I approve publication.
```

The first preview uses the included two shirts and has no generation cost. Your agent starts there before asking you to connect a video model.

When you are ready to customize it, share a product photo or your print. You can tell the agent what you like in ordinary language: “keep this fabric,” “make the turn gentler,” or “use this brand’s colors.” It prepares the files and shows you the result.

You will review the image pair, approve a budget if new generation is needed, and review the website before release. The agent checks available tools and explains any account or permission step it cannot complete for you.

## Agent entry

Read [docs/agent-workflow.md](docs/agent-workflow.md) and execute the first preview phase now. Use [prompts/agent-bootstrap.md](prompts/agent-bootstrap.md) to continue with custom assets. Keep technical commands in your own work; report the preview URL and the next concrete decision to the user.
