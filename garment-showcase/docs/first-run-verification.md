# First-run verification

On 19 October 2026, a new Codex chat received the source ZIP link and a plain-language request to open the example. It had no project conversation or previous project source. Existing account tools and a Node.js installation remained available.

The agent downloaded and extracted the package into a new directory, read its instructions, started a loopback server and opened the example. No dependency installation, API account, generation payment or manual code edit was needed.

Verified: both shirts rendered; pointer activation reached the front frame and exit returned to profile; both detail dialogs and front/back controls worked; keyboard selection worked; a narrow viewport supported mouse-drag browsing. The 11 Node tests, asset audit and static build passed. Captured browser logs contained no warnings or errors.

The local execution sandbox initially blocked networking. The agent used the environment's permission flow and continued. A different host may require permission to install Node or allow a local server.

This verifies the bundled example in one Codex environment. It does not establish equivalent behavior in every coding agent, a fresh operating system, physical-phone touch, or a full paid generation run. Product-specific animation requires suitable footage or access to a generation tool. The repository includes instructions for those steps.
