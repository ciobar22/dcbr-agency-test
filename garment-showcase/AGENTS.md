# Agent entry: run the experience for the user

The user may know nothing about coding. Your job is to deliver a working local clothing website, then guide its visual adaptation. Read START-HERE.md and docs/agent-workflow.md. README.md is the human overview; docs/workflow.md contains the technical recipe.

## First response and action

Start the bundled example before a long intake. Inspect the project and environment, find or prepare Node.js, run scripts/serve.mjs, check the actual page and open its local URL. Handle setup yourself where tools and permission allow. Ask the user for a specific unavoidable account, permission or missing input only after completing independent work. Do not ask them to design an architecture, edit JSON, install packages manually or choose a runtime when you can resolve those steps.

## Customization

- Ask for one product’s photos or original artwork and the desired visual direction. Infer technical defaults from the working example
- Inspect source images before editing. Detect available image/video tools yourself; state a missing integration accurately and offer a concrete connection/import path
- Preserve product identity, matched scale, strict side profile, one quarter-turn, fixed suspension point and a separate static wire
- Show the front/profile images for visual review before new video generation
- Before an external upload or paid generation, agree on the provider, request settings, upload scope, total cap and attempt limit. Reuse existing authorization; do not ask again within it
- Save generation receipts and job IDs; resume an existing job after a timeout instead of repeating an uncertain submission
- Keep credentials in a local environment or ignored .env.local, never in prompts, browser files, git or screenshots. Guide private entry when a key is missing
- Process footage and update the catalog yourself. Keep inputs/, generated/, work/ and review/ private. Publish only intentionally reviewed assets
- Preserve reversible hover, neighbor opacity, touch browsing, keyboard behavior and reduced motion. Review each video at actual UI speed, on contrasting backgrounds, including interruptions and reversal
- Run meaningful checks and show the local result. Publish only on explicit approval, then verify the public URL

Use the project’s existing architecture. Complete one garment before expanding. Report verified results, unresolved limitations and recorded spend. The generated examples and the code have separate release terms; see LICENSE-ASSETS.md.
